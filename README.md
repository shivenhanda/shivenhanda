# 🌟 Portfolio

> A professional portfolio website built with React, Vite, and Framer Motion.

🔗 Live Demo: **https://shivenhanda.vercel.app/**

---

## 📝 Description

This project is a personal portfolio website designed to showcase the work, skills, and projects of **Shiven Handa**.

Built with **React** and **Vite**, the website provides a fast, responsive, and modern user experience. It uses **Tailwind CSS** for styling and **Framer Motion** for smooth animations and transitions. Navigation is managed using **React Router DOM** for seamless page transitions.

---

## ✨ Key Features

- 🎨 **Styled with Tailwind CSS**  
  Modern, responsive, and utility-first design.

- ✨ **Animations with Framer Motion**  
  Smooth transitions and engaging UI effects.

- ⚡ **Fast Development with Vite**  
  Lightning-fast builds and optimized performance.

- 🛣️ **React Router Navigation**  
  Seamless client-side routing experience.

## ⚡ Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/shivenhanda/portfolio.git

# 2. Move into the project folder
cd portfolio

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```
